# 02 · Prompt Templates

> 三组**反复验证过的** prompt 模板，替代 90% 场景里的烂 prompt。

## 设计原则

我们收的不是"花哨的 prompt"，是**经过反复验证的、能稳定产出 X 的模板**。每条都满足：

1. **结构化输出**：明确告诉 AI "我要 6 段，第 1 段是 X，第 2 段是 Y..."，不留余地
2. **判据先行**：在 prompt 里就把 "什么叫做对" 写清楚
3. **替代物**：每条都明确替代了某种常见的烂 prompt

## 三组模板

| 模板 | 替代什么 | 用途 |
|---|---|---|
| [templ-1: 读论文](./templ-1-read-paper.md) | "总结这篇 paper" | 把 paper 变成结构化笔记，含 invariant + 复现成本 |
| [templ-2: 写笔记](./templ-2-write-notes.md) | "帮我总结一下" | 用 spec-driven 流程写出"3 个月后能看懂"的笔记 |
| [templ-3: 跑实验](./templ-3-run-experiment.md) | "帮我实现 X" | TDD-first 实现，避免 Self-Evaluation Bias |

## 怎么用

每个模板文件包含：

- **背景**：解决什么问题
- **使用方法**：复制粘贴时的占位说明
- **使用示例**：真实 case + 期望输出
- **故障排查**：常见输出问题及修法

直接复制 prompt 段到你的 AI Agent 输入框，把 `[占位符]` 换成你的内容。

## 经验法则

> **3 千字以下的笔记可以直接写。3 千字以上的综述、博客、论文，spec-driven 是稳赚的。**

- 越复杂的任务，prompt 模板的回报越大
- 简单任务直接说就行，套模板反而冗余
- 模板是 baseline；用熟了请按你课题特点 fork 自己的版本
